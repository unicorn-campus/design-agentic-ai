# 신용카드사 Help Desk 유저스토리

## 1. 범위

`W-01`, `W-02`, `W-03`별 핵심 사용자 기능 요구사항(User Functional Requirement, UFR) 1건씩만 정의함.
LLM, 예측형 AI, 결정론적 처리기는 사용자가 아니라 처리 참여 주체임.

| UFR ID | 워크플로우 | 사용자 역할 | 원하는 결과 | MoSCoW | Story Point |
|---|---|---|---|---|---|
| `UFR-HDS-010` | `W-01` | 인증된 카드 고객 | 근거가 표시된 답변 또는 맥락이 유지된 상담사 연결 | Must | 8 |
| `UFR-HDS-020` | `W-02` | 지식 검토자 | 근거와 우선순위가 있는 FAQ 개선 후보의 검토·승인 | Must | 8 |
| `UFR-HDS-030` | `W-03` | 상담사 | 상담 종료 후 안전한 CRM 기록과 동의 고객 설문 발송 | Must | 8 |

## 2. `UFR-HDS-010` 근거 기반 고객 문의 처리

인증된 카드 고객으로서 카드 문제의 원인과 다음 행동을 이해하기 위해 근거가 표시된 답변을 원함.

### 요구사항

| 항목 | 내용 |
|---|---|
| 비즈니스 목적 | 첫 답변 시간과 재문의 감소, 안전한 자동 해결률 향상 |
| 입력 | 인증 세션, 1자 이상 2,000자 이하 문의, 채널, 추적 ID |
| 검증 | 인증·권한·민감정보·SQL·출처·답변 마스킹 검사 |
| 성공 | p95 5초 내 근거 답변 또는 맥락이 있는 상담사 인계 |
| 실패 | 상태를 추측하지 않고 안전 안내 후 상담사 대기열 이관 |
| 참여 역할 | `R-D2`, `R-L1`, `R-D1`, 조건부 `R-H1` |
| 지식 | `K-ST-FQ-01`, `K-ST-NL-01`, `K-SEM-01`, `K-REL-01`, 외부정보·사전·온톨로지 |
| 원천 | 읽기 복제본, 마스킹 분석 뷰, 승인 문서, 업무 그래프, 공식 웹·영상 |
| 도구 | 고정 쿼리, NL2SQL 검사기, RAG, GraphRAG, 공식 출처 커넥터, 예측 API |
| 사람 개입 | 위험 점수 0.80 이상, 근거 없음·상충, 고객의 상담사 요청 시 `S-R9` 검토 |

### 인수 기준

| AC ID | Given | When | Then |
|---|---|---|---|
| `AC-010-1` | 인증·권한이 유효한 문의 | 고정 쿼리와 읽기 전용 NL2SQL을 수행함 | 허용 열·100행 이내 결과만 답변 근거로 전달됨 |
| `AC-010-2` | 대표어로 정규화된 문의 | RAG·GraphRAG·온톨로지로 근거를 검색함 | 문서 ID·버전·3홉 이내 관계 원천이 표시됨 |
| `AC-010-3` | 공식 외부 근거가 필요함 | 비식별 검색어로 웹·영상 경로를 조회함 | URL·제목·조회 시각과 영상 자막 구간이 표시됨 |
| `AC-010-4` | 위험 점수 0.80 이상 또는 근거 상충 | 답변 초안과 판단 정보를 상담사에게 제시함 | 승인·수정·중단 전에는 답변과 상태 변경을 확정하지 않음 |
| `AC-010-5` | 모든 검사가 통과된 저위험 답변 | 답변을 고객에게 전달함 | 근거와 다음 행동이 표시되고 민감정보 원문은 없음 |

## 3. `UFR-HDS-020` 일일 FAQ 개선 후보 검토

지식 검토자로서 반복 문의를 줄이기 위해 전일 상담에서 만든 근거 있는 FAQ 개선 후보를 검토하고 싶음.

### 요구사항

| 항목 | 내용 |
|---|---|
| 비즈니스 목적 | 반복 문의·오답 후보 발견과 지식 개선 시간 단축 |
| 입력 | 전일 종료 상담, 마스킹 통계, 내부·공식 외부 근거 |
| 검증 | 실행 ID 멱등성, 읽기 SQL, 중복 후보, 출처, 민감정보, 승인 권한 검사 |
| 성공 | 06:00 이전 후보 최대 20건 생성 후 승인 대기열 등록 |
| 실패 | 단계별 1회 재시도 후 실패 후보 제외 또는 운영자 알림 |
| 참여 역할 | `R-D2`, `R-L1`, `R-D1`, `R-H1` |
| 지식 | 지식 ID 8종 전체 사용 |
| 원천 | 상담 읽기 복제본, 분석 뷰, 승인 문서, 업무 그래프, 공식 웹·영상 |
| 도구 | 스케줄러, 고정 쿼리, NL2SQL 검사기, RAG, GraphRAG, 예측 API, 승인 대기열 |
| 사람 개입 | `S-B9`에서 근거·표현·준법을 확인하고 승인·수정·반려함 |

### 인수 기준

| AC ID | Given | When | Then |
|---|---|---|---|
| `AC-020-1` | 매일 02:00이며 동일 실행이 없음 | 전일 상담 고정 쿼리와 집계 NL2SQL을 수행함 | 마스킹 자료와 검사된 최대 100행 통계가 생성됨 |
| `AC-020-2` | 반복 문의와 내부 근거가 있음 | 사전·RAG·GraphRAG·온톨로지로 주제를 묶음 | 원천이 있는 개선 주제 최대 100개가 생성됨 |
| `AC-020-3` | 공식 변경 확인이 필요함 | 웹·영상 결과를 비신뢰 입력으로 검사함 | 재확인 가능한 출처만 후보 근거에 포함됨 |
| `AC-020-4` | 빈도·위험·재문의율이 준비됨 | 예측형 AI로 개선 우선순위를 산출함 | 점수와 모델 오류 여부가 검토자에게 표시됨 |
| `AC-020-5` | FAQ 후보와 근거가 준비됨 | 검토자가 승인·수정·반려함 | 승인 ID가 있는 후보만 등록되고 자동 게시되지 않음 |

## 4. `UFR-HDS-030` 상담 종료 후처리

상담사로서 다음 상담에 안전하게 맥락을 전달하기 위해 종료된 상담의 마스킹 요약과 CRM 기록을 원함.

### 요구사항

| 항목 | 내용 |
|---|---|
| 비즈니스 목적 | 상담 후처리 시간 감소와 기록 누락 방지 |
| 입력 | `eventId`, 상담 ID, 종료 시각, 상담 원문, 설문 수신 동의 |
| 검증 | 이벤트 스키마·멱등키·민감정보·요약 누락·CRM 승인·설문 동의 검사 |
| 성공 | p95 60초 내 CRM 기록, 동의 고객에게 설문 1회 발송 |
| 실패 | 성공 단계는 되돌리지 않고 실패 단계만 격리 큐에서 재처리 |
| 참여 역할 | `R-D2`, `R-L1`, `R-D1`, 조건부 `R-H1` |
| 지식 | `K-GLS-01`, `K-SEM-01` |
| 원천 | 마스킹 상담 원문, 승인 상담 지침·FAQ, CRM, 설문 동의 정보 |
| 도구 | 이벤트 버스, 마스킹 검사기, RAG, 예측 API, CRM·설문 커넥터, 격리 큐 |
| 사람 개입 | 위험 점수 0.80 이상 또는 분쟁 징후이면 `S-E5`에서 승인·수정함 |

### 인수 기준

| AC ID | Given | When | Then |
|---|---|---|---|
| `AC-030-1` | 신규 상담 종료 이벤트 | 스키마와 멱등키를 검사하고 원문을 마스킹함 | 중복은 무시되고 민감정보 탐지 실패는 격리됨 |
| `AC-030-2` | 마스킹 원문과 승인 지침 | 용어사전과 RAG를 사용해 상담을 요약함 | 문의 사유·확인 내용·안내 결과·후속 조치가 포함됨 |
| `AC-030-3` | 요약과 고정 위험 특성 | 예측 점수를 산출하고 고위험 기록을 검토함 | 승인된 마스킹 요약만 CRM에 저장됨 |
| `AC-030-4` | CRM 저장 성공과 수신 동의 | 설문 발송을 요청함 | 상담 원문 없는 링크가 한 번 발송되고 결과가 기록됨 |
| `AC-030-5` | CRM·설문 호출 실패 | 정해진 횟수만 재시도함 | CRM 2회·설문 1회 초과 시 격리와 운영자 알림이 생성됨 |

## 5. 공통 비기능 요구사항

### `NFR-PER-010` 성능

- `W-01` p95 5초, `W-02` 06:00 이전, `W-03` p95 60초를 교육용 목표로 측정함.
- 단계별 타임아웃과 재시도 횟수를 감사 로그에 기록함.
- 인수 기준 `AC-NFR-PER-1`: 정상 부하에서 세 목표를 각각 충족하고 초과 구간을 식별 가능함.

### `NFR-PRI-010` 개인정보 보호

- 카드번호 전체, CVC, 비밀번호, 주민등록번호, 인증 토큰의 프롬프트·외부 검색어·로그 유입 금지임.
- 사용자·웹·영상 문자열은 `<untrusted_contents>`로 분리하고 지시문 무시, 길이·형식·허용 필드 검사 적용함.
- 입력 검사와 출력 마스킹 실패 시 모델·외부 도구 호출 전에 안전 종료함.
- 인수 기준 `AC-NFR-PRI-1`: Prompt Injection과 민감정보 시험 문자열이 실행·로그·응답에 반영되지 않음.

### `NFR-AUD-010` 감사 기록

- 추적 ID, 단계 ID, 역할, 모델·도구 버전, 지식 ID·원천, 승인자, 시각, 결과, 오류를 기록함.
- 외부 웹·영상은 URL·제목·조회 시각·자막 구간을 기록하며 원문 민감정보는 저장하지 않음.
- 인수 기준 `AC-NFR-AUD-1`: 고객 답변·FAQ 후보·CRM 기록에서 사용 근거와 사람 결정을 역추적 가능함.
