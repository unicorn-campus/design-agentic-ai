**아티클 고유 지시 (위 공통 규격 뒤에 추가로 수행함)**

- 고유-1 진입점 현행성 판정 — LangChain 1.0이 2025-10-22 GA된 이후 표준 진입점이
  `create_agent` + 미들웨어(middleware)로 이동한 상태임. 원문이 `create_agent`를 쓰는지,
  구 진입점(`AgentExecutor` · `initialize_agent` · LangGraph `StateGraph` 단독 조립)을 함께 제시하는지를
  7절에 `현재 진입점 / 폐기 예정 표기 / 조회 시점` 3항목으로 적음. 원문에 없으면 `원문 미표기`로 적음
- 고유-2 구성 방식 명칭은 원문 표기 그대로 — 원문이 제시하는 멀티에이전트 구성 방식(핸드오프·서브에이전트 등)의
  **명칭과 코드 진입점을 번역·의역 없이 원문 문자열 그대로** 3절·7절에 옮김.
  한국어 설명은 `handoffs(핸드오프)` 형태의 괄호 병기로만 붙이고, 명칭 자체를 한국어로 바꾸지 않음
- 고유-3 하위 페이지 처리 — `/multi-agent` 아래 하위 페이지가 존재하면 3절 표에 하위 경로 목록과 1줄 설명을 넣음
  (2026-08-05 `context7` 조회 기준 `/multi-agent/handoffs` · `/multi-agent/subagents` 경로가 확인됨.
  실제 판독 시 원문에서 재확인함). 판독하지 않은 하위 페이지는 8절 `미확인`에 경로 단위로 적음
- 고유-4 열린 질문 연결 — `references/recommend-materials.md` 2절 8번은
  `커리큘럼 4-3절 LangGraph 단독 사용`과 `create_agent`+미들웨어 표준의 충돌을 스타터 리포지토리 진입점
  결정 안건으로 올려 둔 항목임. 원문에서 이 충돌과 연결되는 서술(예: 미들웨어가 대체하는 기능,
  `StateGraph` 직접 조립의 위치)이 확인되면 **9절 열린 질문에 1행 이상 올림**
- 고유-5 코드 교차 확인 — 원문 코드블록을 옮길 때 `context7` MCP로 현행 API 시그니처를 교차 확인함.
  원문 표기와 `context7` 결과가 다르면 6절에 차이를 1줄 기록함.
  실행해 보지 않은 코드는 문서에 `미검증 스케치`라고 명시함
- 고유-6 조회일 병기 재강조 — `/oss/python/` 경로 문서는 본문에 버전 표기가 없으므로 공통 규격 R6에 따라
  `docs.langchain.com/oss/python/langchain/multi-agent {실제 조회일 YYYY-MM-DD} 조회 기준`을
  1절 메타표와 2·3·4·7절 인용 앵커 양쪽에 병기함. 조회일을 생략한 앵커는 규격 위반임

**해설본 작업 (산출물 2 — 쉬운 한글 해설본)**

- 목적이 다름 — 산출물 1(정리본)은 교재 집필자가 인용을 찾는 참조용이고,
  산출물 2(해설본)는 **원문을 읽지 않을 사람이 내용을 이해하는 학습용**임.
  같은 내용을 두 번 쓰지 않음. 해설본에는 출처 앵커·인용표를 넣지 않음
- 원문 접근은 **Playwright MCP를 주 경로**로 사용함 (2026-08-05 실측으로 확정)
  - `ToolSearch`로 도구 로드:
    `select:mcp__pw__browser_navigate,mcp__pw__browser_evaluate,mcp__pw__browser_take_screenshot,mcp__pw__browser_close,mcp__pw__browser_wait_for`
  - `browser_navigate` → `browser_evaluate`로 **목차 먼저** 확보 → 본문 확보 → 이미지 처리 → `browser_close`
  - `browser_evaluate` 시 `style` · `script` · `noscript` · `nav` · `footer`를 제거하고 `textContent`를 사용함
    (`innerText`는 렌더 문제로 0자가 나올 수 있음 — 실측 확인됨)
  - 실패 시 `mcp__claude-in-chrome__*` → `curl -sL` 순으로 폴백하고 확보 수단을 8절에 기록함
- 본문·목차 추출은 아래 스니펫을 사용함

```js
() => {
  const a = document.querySelector('article') || document.querySelector('main') || document.body;
  const c = a.cloneNode(true);
  c.querySelectorAll('style,script,noscript,nav,footer').forEach(e => e.remove());
  const text = c.textContent.replace(/\s+/g, ' ').trim();
  const headings = [...document.querySelectorAll('h1,h2,h3')]
    .map(h => h.tagName + '|' + h.textContent.trim()).filter(x => x.length > 4);
  const figures = [...document.querySelectorAll('figure, article img, main img')]
    .map(e => ({ tag: e.tagName, src: e.getAttribute('src') || '', alt: e.getAttribute('alt') || '' }));
  return { len: text.length, headings, figures, text: text.slice(0, 20000) };
}
```
