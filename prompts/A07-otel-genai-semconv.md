**해설본 작업 (산출물 2 — 쉬운 한글 해설본)**

- 목적이 다름 — 산출물 1(정리본)은 교재 집필자가 인용을 찾는 참조용이고,
  산출물 2(해설본)는 **원문을 읽지 않을 사람이 내용을 이해하는 학습용**임.
  같은 내용을 두 번 쓰지 않음. 해설본에는 출처 앵커·인용표를 넣지 않음
- 원문 접근은 **Playwright MCP를 주 경로**로 사용함 (2026-08-05 실측으로 확정)
  - `ToolSearch`로 도구 로드:
    `select:mcp__pw__browser_navigate,mcp__pw__browser_evaluate,mcp__pw__browser_take_screenshot,mcp__pw__browser_close,mcp__pw__browser_wait_for`
  - `browser_navigate` → `browser_evaluate`로 **목차 먼저** 확보 → 본문 확보 → 이미지 처리 → `browser_close`
  - `browser_evaluate` 시 `style` · `script` · `noscript` · `nav` · `footer`를 제거하고 `textContent`를 사용함
    (`innerText`는 렌더 문제로 0자가 나올 수 있음 — 실측 확인됨)
  - 실패 시 `mcp__claude-in-chrome__*` → `curl -sL` 순으로 폴백하고 확보 수단을 8절에 기록함
- 본문·목차 추출은 아래 스니펫을 사용함

```js
() => {
  const a = document.querySelector('article') || document.querySelector('main') || document.body;
  const c = a.cloneNode(true);
  c.querySelectorAll('style,script,noscript,nav,footer').forEach(e => e.remove());
  const text = c.textContent.replace(/\s+/g, ' ').trim();
  const headings = [...document.querySelectorAll('h1,h2,h3')]
    .map(h => h.tagName + '|' + h.textContent.trim()).filter(x => x.length > 4);
  const figures = [...document.querySelectorAll('figure, article img, main img')]
    .map(e => ({ tag: e.tagName, src: e.getAttribute('src') || '', alt: e.getAttribute('alt') || '' }));
  return { len: text.length, headings, figures, text: text.slice(0, 20000) };
}
```
