# 아티클 정리 프롬프트 세트 (10건)

작성: 2026-08-05 · 팀: design-agentic-ai · 통합: 클로니(오케스트레이터)

`references/recommend-materials.md` 1절 **최우선 10건**을 정리하기 위한 실행용 프롬프트 모음임.
프롬프트 1개를 실행하면 **문서 2개**가 생성됨.

| 산출물 | 위치 | 무엇인가 | 누가 읽나 |

| 1. 정리본 | `references/articles/` | 교재에 인용할 문장·수치·커리큘럼 대응을 뽑아 둔 참조용 | 교재 집필자 |

같은 내용을 두 번 쓰지 않음. 정리본에는 비유·그림이 없고, 해설본에는 출처 앵커·인용표가 없음.

## 사용법

- 프롬프트 파일 1개를 통째로 복사해 실행함. **공통 규격 파일을 열지 않아도 실행 가능**하도록
  필요한 규격이 각 파일에 인라인 복사되어 있음
- 10건을 순서대로 실행할 필요는 없음. 서로 독립적임
- 실행 전 `.temp/` 디렉터리가 있어야 함(원문 `curl` 저장 위치)
- 해설본 작업은 **Playwright MCP**(`mcp__pw__*`)를 사용함. 실행 전 `ToolSearch`로 도구를 로드해야 함
