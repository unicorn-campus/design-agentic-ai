## ② 요약 품질 규칙

- **R1 출처 앵커 필수** — 2·3·4·7절의 모든 사실 문장 끝에 앵커 1개.
  형식 `[§3.2]` / `[p.14]` / `[표: {제목}]` / `[commit YYYY-MM-DD]`. 앵커 없는 사실 문장 0개
- **R2 사실·추론 분리** — 해석·추론은 `(추론)` 접두어 + 근거 1줄. 6·9절에서만 허용, 나머지 절 0개
- **R3 수치 5요소 병기** — ① 값·단위 ② 표본·측정 대상(n) ③ 시점 ④ 측정 주체
  ⑤ 독립 여부(독립조사 / 벤더 자체 / 벤더 후원). 없는 요소는 `원문 미표기`
- **R4 인용 상한** — 연속 인용 1건당 영문 40단어 / 국문 100자 이내, 문서당 최대 6건. 큰따옴표 + 앵커.
  **여기서 `인용`은 큰따옴표로 감싼 직접 인용만 뜻함** — 자기 표현으로 바꾼 요약·재서술은 세지 않음
- **R5 확인 상태 4단계**
  - `FULL` 본문 전문 판독 → 전 섹션 작성. 판정 기준은 미판독분이 **본문이 아닌 요소**
    (표지·목차·로고·광고·참고문헌 목록)뿐인 경우임
  - `PARTIAL` 일부만 판독 → 2·4절에 `※ 판독 범위: {범위}` 1줄 필수
  - `META` 서지만 확인 → 2·4절 작성 금지, `본문 미판독으로 미작성` 1줄만
  - `FAIL` 접근 실패 → 1·8·9절만 작성. 8절에 시도 방법·오류·재시도 조건 기록
- **R6 변동 자료 조회 시점** — 버전 없는 자료(GitHub main, `/stable/`, `latest`)는
  `{경로} YYYY-MM-DD 조회 기준`을 1절과 앵커 양쪽에 병기
- **R7 발행일 근거 명시** — 값만 쓰지 않고 근거 종류 괄호 병기. 예: `2026-07(최종 커밋일)`
- **R8 용어 표기** — 영문 전문용어는 최초 1회만 `한국어(English)` 병기, 이후 한국어 단일
- **R9 금지 표현** — `일반적으로` `업계 표준` `대부분` `~라고 알려짐` 등 출처 없는 일반화 0개
- **R10 상충 표시** — `recommend-materials.md` 5절 상충 2건에 걸리면 6절에
  `※ 상충: {상충명} — 반대 입장 {자료명}` 1줄

## ⑤ 개별 프롬프트에 인라인 복사할 텍스트 블록

각 프롬프트의 `[처리]`·`[출력]`·`[제약조건]` 섹션에 아래를 복사하고 `{중괄호}`만 채움.
아티클 고유 지시(예: 특정 절 집중 판독)는 이 블록 **뒤에** 별도 항목으로 추가함.

```text
[처리]
- 원문 확보: `curl -sL {원문 URL} > .temp/{저장 파일명}` 실행 후 본문 판독함.
  403·JS 셸·타임아웃 시 재시도 1회 후 결과를 확인 상태로 기록함
- 확인 상태를 4단계 중 1개로 판정함
  - FULL: 본문 전문 판독 / PARTIAL: 일부만 판독 / META: 서지만 확인 / FAIL: 접근 실패
  - `FULL` 판정 기준 — 미판독분이 본문이 아닌 요소(표지·목차·로고·참고문헌 목록)뿐인 경우임
  - PARTIAL 이하이면 판독하지 못한 범위를 문서 8절에 그대로 기록함
- 아래 9개 섹션을 규격 문자열 그대로 작성함 (제목 변경·순서 변경·추가 금지)
  - `# A{NN} {자료 한국어 제목}` (1줄)
  - `## 1. 한눈에 보기` — 고정 9행 메타표 (원문 URL / 발행·갱신일 / 발행 주체 / 자료 유형 /
    확인 상태 / 확인 방법·시점 / 저장 파일 / 한 줄 요지 / 1차 대응). 빈칸 금지, 없으면 `미확인`
  - `## 2. 핵심 주장` — `C1`~`C5` 번호 부여, 항목당 1~3줄, 25줄 이내
  - `## 3. 원문 구조` — 원문 장·절과 1줄 설명, 표 15행 이내
  - `## 4. 인용 가능 문장·수치` — `Q1`~`Q8` 번호 부여, 표 8행 이내
  - `## 5. 커리큘럼 대응` — 열 5개(교육 / 위치 / 용도 / 가져올 것 / 집필 메모), 표 8행 이내
  - `## 6. 집필 시 주의` — 한계·반박·상충·유효기간, 15줄 이내
```
