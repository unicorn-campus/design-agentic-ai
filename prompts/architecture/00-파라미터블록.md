## 1. 표기·치환 규약

| 규칙 | 내용 |
|------|------|
| 표기 | 변수는 `{중괄호}`로 표기함. 2절에 선언된 15개 변수명만 사용하며 임의 신설을 금지함 |
| 타입 | `단일값`(문장 삽입) / `레코드`(선언된 필드 보유) / `목록`(행 가변 표) / `경로` 4종 |
| 필드 인용 | 레코드형 변수의 특정 필드는 `{변수명·필드명}`으로 인용함(예: `{케이스 정의·도메인}`) |
| 목록 삽입 | 목록형은 표 자리에 통째로 삽입하거나 `{변수명}의 전부`를 이름으로 씀. 개별 행 인용은 `{변수명}:{행 키}` |
| 미기입 | `선택` 변수가 미기입이면 해당 변수를 참조하는 줄·칸을 **제거**함. 추정값으로 채우지 않음 |
| 필수 미기입 | `필수` 변수가 미기입이면 프롬프트를 실행하지 않음. 5절 기입란 검증에서 차단함 |
| 대소문자·구두점 | 치환 후 문장의 조사는 앞 단어 받침에 맞춰 교정함. 치환 흔적 판정 대상은 2절 변수명 토큰으로 한정하며, 아래 `자리표시자 구분` 행의 토큰과 코드블록 내 정규식(문자 패턴을 적는 표기법)·JSON 예시가 남는 것은 미완성으로 판정하지 않음 |
| 자리표시자 구분 | 태그·경로·인용 서식의 자리표시자(`[확인필요: {항목명}]` · `[범위외: {제외 항목명}]` · `{번호}` · `{산출물명}` · `{약칭}:{ID}#{하위}` · `{문서 약칭}:{항목 ID}#{하위 항목}` · `{블록명}{순번}` · `{에이전트명}` · `{변수명}` · `{근거ID}` · `{절 이름}` · `{항목명}` · `{제외 항목명}` · `{소유 산출물 번호}` · `{행 키}` · `{해당 행 키}` · `{변수}` · `{중괄호}` · `{변수명·필드명}` · `{계열명}` · `{산출물 번호}` · `{역할}` · `{총 기간}` · `{단계 수}` · `{W-n}` · `{수행 형태}` · `{n}` · `{NN}` · `{금지 표현}` · `{탈락 사유}`)는 파라미터 변수가 아님. 5절 기입란에 채우는 대상이 아니고, 작성할 때 실제 값으로 바꿔 씀. 이 행의 목록이 전부이며, 새 자리표시자를 본문에 쓰려면 먼저 이 행에 올려 적음. 코드블록 내 정규식 수량자(`{2,6}`·`{4,}`)·JSON 예시 키·3절 사례 값의 ID 패턴(`{MBR\|REC\|PAY}`·`{3자리}`)도 검사 대상이 아님 |

- (주3) 사례 A의 BM·US 본문이 미확보 상태이므로 경로 칸이 `프로젝트 확정 필요`임. 6절 1단계 검사 (1)에서  
  차단되므로 두 경로를 기입한 뒤 실행함. 경로는 기입되었으나 본문 조회에 실패하면  
  [기획 산출물 참조 규약](00-기획산출물참조규약.md) 2절 `BM·US 결손 규칙`을 적용함

표 하단 용어 뜻풀이 — 사례 값에 나오는 용어의 뜻임. 표 안의 표기는 그대로 씀.  
- `NL2SQL`(말로 물으면 SQL로 바꿔 답을 찾는 방식) · `GraphRAG`(문서를 그래프로 엮어 관계까지 따라 찾음) ·  
  `벡터 RAG`(뜻이 비슷한 문서를 찾아 근거로 씀) · `MCP`(AI가 외부 도구·데이터에 붙는 표준 규격) ·  
  `LangGraph`(작업 순서를 그래프로 그려 실행하는 틀)
- `엣지 캐싱`(사용자 가까운 서버에 미리 담아 둠) · `오토스케일링`(부하에 따라 서버 수를 자동 조절) ·  
  `멀티테넌시`(한 시스템을 여러 고객이 나눠 씀)
- `하드 필터`(조건에 걸리면 아예 빼는 걸러내기) · `Mock`(실물 대신 두는 대체품)

기입 근거 규약 — 사례 B 칸은 비즈니스 모델 문서·유저스토리 문서 2종에서 확인된 값만 기재함.
