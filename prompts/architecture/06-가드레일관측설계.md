[작업방법]
0. 입력 가용성을 확인함. 기획 산출물 3종과 선행 설계 산출물의 존재 여부를 점검하고, 부재 항목을

   작성을 중단하지 않음. ③ 부재 시 오버레이 단계 목록 칸을 `[확인필요: 선행 미생성]`으로 남기고 ①만으로
   시작 가능한 품질 측정 대상·문항 수 부분을 먼저 작성함
1. ③의 **트리거별 시퀀스 전부**와 동일한 단계 구성을 그대로 가져와 `오버레이 1장`을 작성함. 단계 추가·
   삭제·병합을 하지 않고 각 단계에 태그만 붙임. 단계마다 아래 5문을 예/아니오로 판정해 붙일 태그를
   정하고, 판정 결과를 오버레이 표의 열로 남김(값은 `예`·`아니오` 2종만 씀)
   - Q1 ③의 단계 목록이 확정됐나 — `아니오`면 그 단계 행을 `[확인필요: 선행 미생성]`으로 둠
   - Q2 이 단계가 **우리가 쓰지 않은 문자열**을 읽나(외부 API 응답·캐시 적재값 포함) — `예`면 입력측 태그.
     **`사용자 자유 입력`으로 좁혀 읽지 않음.** 자유 입력창이 없어도 외부 응답의 이름·설명 문자열이
     캐시를 거쳐 모델 입력에 들어가므로, 좁혀 읽으면 입력측 태그가 통째로 0건이 됨
   - Q3 쓰기·발송·과금을 하나 — `예`면 작업방법 10의 승인 지점 후보로 올림
   - Q4 민감 필드를 만지나 — `예`면 마스킹 태그
   - Q5 모델을 부르나 — `예`면 비용·타임아웃 태그, `아니오`면 두 칸을 `해당 없음`으로 씀
2. 단계별 `비용 상한` 태그를 붙임. BM `Cost Structure — 변동비용`·`연간 비용 전망`에서 원래 값 `B`를,
   BM `Revenue Streams — 수익 전망 표`에서 계산에 쓰는 전제값 `N`을 원문 인용한 뒤
   00-기획산출물참조규약.md의 정량값 인용 절차와 비용 상한 환산(단위를 바꿔 다시 계산함) C-1~C-7을 차례로
   수행함 — C-1 원래 값과 전제를 그대로 인용, C-2 기간 단위 통일, C-3 `C_req = B_월 ÷ N_월`, C-4 ③의 모델
   호출 단계와 횟수 `n_i` 인용, C-5 `C_설계 = C_req ÷ M_최악`(`M_최악 = M_재시도 × M_루프`),
   C-6 `w_i = n_i ÷ Σn`으로 호출 횟수에 비례해 나눠 배정, C-7 합계 행에서 `Σ 단계별 상한 ≤ C_설계` 확인.
   앞의 `C-n`은 **비용 환산 계열**이며 CYCLE 순환 쌍 `C-1` ~ `C-3`과 다른 계열임
   ([공통 규약](00-공통규약.md) 4-3절). 아래 5건은 ⑥이 직접 수행하는 계산이며 다른 산출물에 미루지 않음
   - (2-0) **⑤의 `경로별 요청당 토큰 수 전제` 표와 `골든셋 설계` 표를 먼저 인용함** — 요청당 토큰 수는
     ⑤가 소유하므로 ⑥이 새로 정하지 않고 경로별 값을 그대로 옮겨 단가 계산의 입력으로 씀.
     ⑤ 미생성이면 `[확인필요: 선행 미생성]`으로 두고 단계별 상한을 비율(%)로만 나눠 배정함
   - (2-1) **C-1에 단가 판본과 모델 호출 설정을 함께 적음** — 단가표의 판본·조회일과 사고(reasoning)
     사용 여부를 1줄로 적음. 도입 특가는 종료일이 있고, 사고를 켠 모델은 사고 토큰이 출력 단가로 붙어
     원래 값 `B`가 흔들림. 값이 없으면 `[확인필요: 단가 판본]`으로 남김
   - (2-2) **C-3의 나눗셈(`기간 상한 ÷ 건수 전제`)은 ⑥이 수행함** — `{비용 예산 상한}`이 `월` 단위이거나
     BM 값이 연·월 단위이면 요청 1건당 금액으로 반드시 환산하고, 원래 값·환산식·결과값 3개를 함께 적음.
     이 환산을 건너뛰면 월 상한만 남아 단계별 상한을 아무도 세지 못함
   - (2-3) **C-5에서 `M_최악 = M_재시도 × M_루프`를 계층별로 나눠 세어 곱함** — `M_재시도`는
     ③ `타임아웃·재시도` 표의 **`재시도 계층` 열**을 세어 계층마다 `(1 + 재시도 횟수)`를 구한 뒤
     서로 곱한 값임(예: 소비자 재처리 5회 · 대기열 재처리 3회 → `5 × 3 = 15`).
     `M_루프`는 ③ `반복 상한` 표 아래의 `1 + (max_iter × 반복 1회 호출 증분)` 값을
     **그대로 인용함**(⑥이 다시 계산하지 않음. [공통 규약](00-공통규약.md) 4-2절 `M-2`).
     결과를 비용 상한 표에 `최악 배수`·`최악 금액` 2열로 적음.
     이 곱셈을 빼면 요청당 금액이 맞아도 최악 경로에서 예산이 배수로 뚫림
