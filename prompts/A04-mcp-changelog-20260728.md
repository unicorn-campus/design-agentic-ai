**아티클 고유 지시 (위 공통 규격 블록 뒤에 추가로 수행함)**

- 고유-1 변경 4분류 표 강제 — 7절 `## 7. 명세 변경 이력`의 본체를 아래 4열 표 1개로 구성함
  - 열: `구분` / `항목(규격 이름·필드·RPC)` / `직전 개정판 대비 내용` / `앵커`
  - `구분` 허용값: `추가` · `변경` · `폐기 예정` · `파괴적 변경` — 이외 값 사용 금지
  - 직전 개정판의 날짜·판번호를 원문에서 확인해 표 위 1줄로 명시함. 확인되지 않으면 `직전 판 미표기`로 씀
  - 하위호환 조건(기존 클라이언트가 계속 동작하는 조건)을 표 아래 1 ~ 3줄로 분리 기술함.
    원문에 조건 서술이 없으면 `원문 미표기`로 적고 항목 자체를 빼지 않음
  - 표 15행 상한을 넘기면 커넥터 구현 영향이 큰 순서로 15행까지 남기고 나머지는 8절에 건수만 기록함
- 고유-2 기존 기록과 원문 대조 — `references/recommend-materials.md` 2절 1번에 기록된 아래 4개 사항이
  원문에서 실제로 확인되는지 1건씩 대조함
  - ① 핸드셰이크(handshake) 제거 ② `Mcp-Session-Id` 제거로 인한 무상태화(stateless)
  - ③ `Roots` · `Sampling` · `Logging` 3기능 폐기 예정 ④ `server/discover` RPC 필수화
  - 대조 결과를 8절에 `기록 내용 / 원문 확인 결과 / 판정(일치 · 불일치 · 원문 미언급)` 3열 표로 남김
  - **기록과 원문이 다르면 원문을 기준으로 정정함.** 정정이 1건이라도 발생하면 6절에
    `※ 기록 정정: {기록 내용} → {원문 확인 내용}` 1줄을 항목마다 남기고,
    9절에 `recommend-materials.md 2절 1번 정정 필요 — {항목명}` 1줄을 항목마다 추가함
  - 4건 각각을 7절 표에 1행 이상으로 반영하고, 원문에서 확인되지 않으면 `원문 미확인`으로 적고 삭제하지 않음

  **폐기 예정 3기능에 대한 의존 여부를 점검할 항목을 9절 열린 질문에 1행 이상 올림**
  - 기본 문안: `스타터 리포지토리 MCP 클라이언트가 폐기 예정 3기능(Roots · Sampling · Logging)에 의존하는지 점검 필요`
  - 폐기 예정 기능 목록이 원문에서 다르게 확인되면 확인된 목록으로 바꿔 씀
  - 점검 항목에 `어느 기능 / 확인할 대상 / 대체 경로 후보` 3요소를 포함함
  - 본 작업에서 리포지토리 코드를 실제로 열어 확인하지 않았다면 `코드 미확인 상태의 점검 제안`이라고 명시함
- 고유-4 원문 우선 교차 확인 — 필드명·헤더명·RPC명을 옮길 때 블로그·정리본 등 2차 출처를 근거로 삼지 않고

() => {
  const a = document.querySelector('article') || document.querySelector('main') || document.body;
  const c = a.cloneNode(true);
  c.querySelectorAll('style,script,noscript,nav,footer').forEach(e => e.remove());
  const text = c.textContent.replace(/\s+/g, ' ').trim();
  const headings = [...document.querySelectorAll('h1,h2,h3')]
    .map(h => h.tagName + '|' + h.textContent.trim()).filter(x => x.length > 4);
  const figures = [...document.querySelectorAll('figure, article img, main img')]
    .map(e => ({ tag: e.tagName, src: e.getAttribute('src') || '', alt: e.getAttribute('alt') || '' }));
  return { len: text.length, headings, figures, text: text.slice(0, 20000) };
}
