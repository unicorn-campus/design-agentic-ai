# S2.2 공통 정형 데이터 설명

`hybrid-ai-lab/rdb`의 PostgreSQL `public` 스키마를 조회하는 교육용 가상 데이터임.  
실제 고객·상품·가맹점 자료를 사용하지 않으며 고객 ID는 합성 데이터 간 연결 키임.  
재식별 열쇠가 있는 `private` 스키마는 실습 계정으로 접근할 수 없음.

## 테이블과 건수

| 테이블 | 건수 | 주요 컬럼 |
|----------|-----:|-----------|
| `member` | 600 | `member_id`, `segment_id`, `join_date`, `age_band` |
| `card` | 1,200 | `card_id`, `member_id`, `product_id`, `brand`, `issue_date`, `status` |
| `product` | 64 | `product_id`, `product_name`, `effective_date`, `family_card_available` |
| `product_annual_fee` | 133 | `product_id`, `brand`, `base_fee`, `service_fee`, `total_fee` |
| `merchant` | 80 | `merchant_id`, `merchant_name`, `category` |
| `card_txn` | 78,802 | `txn_id`, `card_id`, `merchant_id`, `txn_date`, `amount`, `approval_code` |
| `delinquency` | 6,780 | `member_id`, `base_month`, `overdue_days`, `overdue_count_12m` |
| `lab_metadata` | 7 | `key`, `value` |

`delinquency`의 기본 키는 `member_id + base_month` 복합 키임.  
금액은 정수 원 단위, 날짜는 `YYYY-MM-DD`, 기준월은 `YYYY-MM` 형식임.  
제약과 인덱스는 [공통 RDB 스키마](../../rdb/init/01_schema.sql) 참조.

## 상품과 연회비 조회

연회비는 상품·브랜드별로 다르므로 `card.product_id + card.brand`를  
`product_annual_fee.product_id + product_annual_fee.brand`와 함께 조인해야 함.

## 생성·조회 범위

- 거래 기간: 2025-08 ~ 2026-08의 13개월임.  
- 기본 조회: 2026-03 ~ 2026-08의 6개월임.  
- 사용액: 고객의 모든 카드에서 `APPROVED` 거래만 합산함.  
- 취소 거래: `CANCELLED`로 표시하며 승인 금액과 합산하지 않음.  
- 보유 상품: `ACTIVE` 카드만 조회함.  
- 조회 기준일: 2026-03-01 ~ 2026-08-31 범위를 지원함.  
- 연체 자료 누락: 0건으로 확정하지 않고 `확인 필요`로 표시함.

## 직접 확인할 사례

| 고객 | 기대 결과 |
|------|-----------|
| `M-1042` | 3월 ~ 8월 사용액 1,574,000 / 1,495,000 / 1,416,000 / 1,338,000 / 1,259,000 / 1,180,000원 |
| `M-3099` | 8월 연체 자료 누락, 7월 자료 반환 및 현재 월 `확인 필요` |
| `M-3100` | 연체 자료 전체 누락, `확인 필요` |

`M-1042`의 2026-05 대비 2026-08 변화율은 약 -16.7%임.  
취소 거래를 잘못 합산하면 위 금액과 일치하지 않음.

## 기동과 연결

프로젝트 루트에서 다음 명령으로 공통 RDB를 기동함.

```text
docker compose -f hybrid-ai-lab/rdb/compose.yml up -d
```

S2.2는 읽기 전용 `lab_user`로 `public` 스키마만 조회함.  
데이터 초기화·변경은 수행하지 않음.  
상세 절차는 [공통 RDB 안내](../../rdb/README.md) 참조.
