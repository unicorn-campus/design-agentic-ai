# 8단계 결정: 채우기 시험 2라운드 결과와 다음 할 일

- 정할 것: 이 결과로 통과(9단계)할지, 아래 고칠 안으로 3라운드를 할지. 그리고 4절의 "번거로워요" 판정
- 반복 한도: 5회 중 2회 사용. LLM은 Groq `openai/gpt-oss-120b`
- 결론 먼저: 승인한 채점 기준으로 **21개 중 10개 통과**, **연결 검사는 통과**. 고친 설명은 업종, 제안 성격, 불만 주제, 기한 뽑음을 낫게 했으나
  상담의 카드 뽑음은 나빠짐. 남은 미달의 절반은 다시 기대 답(특히 R4)과 채점 방식 탓임

덧붙임

- 혜택 X1 잘못 뽑음이 86%로 오른 것은 채점 탓임. 새 규칙으로 혜택마다 받는 방식이 늘 채워져, 업종이 없어도 "뽑음"으로 셈(2절 가3)

## 3. 남은 미달의 원인

| 질문 | 원인 | 근거(예) |
|---|---|---|
| R4 | 기대 답 | 잘못 뽑음 3건이 또 실제 상황별 처리 문장임(제8조 "등록 전 발생한 거래는 → 확인하여 처리", 제18조 "잔액이 부족하면 → 순차 차감", 제32조 "업무를 위탁할 때 → 공개"). LLM이 쓴 R4 기대 답이 조항마다 덜 뽑혀 있음 |
| R3, B1 | 채점 | 기대 답은 문장 여러 개를 " / "로 이었고 뽑은 값은 그중 하나라, 맞는 조각이어도 "값 다름"으로 셈(예: 제9조 기대 답 두 문장 중 "청구 전에 회원에게 안내합니다"를 뽑음) |
| 혜택 X1 | 채점 | 받는 방식만 있고 업종이 없는 혜택도 "뽑음"으로 셈 |
| C1, A1, 상담 X1 | 추출, 정답표와 규칙의 충돌 | 불만이 없는 상담 4건에서 불만을 뽑음. "걱정돼서요", "불편한 고객으로 보일까 봐"(앞으로의 걱정), "영수증은 못 맞춰요"(할 수 없다는 말)는 설명의 비해당인데 뽑음. "번거로워요"는 설명대로라면 감정 표현이라 불만이 맞지만, 강사용 정답표는 불만으로 보지 않음 |
| 상담 X2 | 추출 | 18건 중 12건에서 카드를 못 뽑음. 카드 이름이 상담사 마무리 발화("…내용을 한빛 가족돌봄 카드 상담으로 기록하겠습니다")에만 있어, LLM이 판에 박힌 말로 넘긴 것으로 보임 |
| R2, C4 | 추출(표본 작음) | R2는 답 있는 표본 6건 중 3건, C4는 8건 중 5건 뽑음 |
| A2 | 표본 | 값 같음은 기준을 넘었고(67%), 답 없는 표본 1건에서 뽑아 잘못 뽑음이 100%가 됨 |

열 뜻

- 원인: 기대 답, 채점, 추출, 표본(표본이 작아 판정이 흔들림)
- 근거: 2라운드 시험 결과에서 본 예. 전체는 `{doc}/output/fill_report.md`
