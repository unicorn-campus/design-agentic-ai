# Help Desk 문의 화면 프로토타입

> 기존 프로토타입이 없어 사용자 승인에 따라 최소 구조를 직접 설계함.

| 요소 | 역할 | 상태 | Vue 컴포넌트 | 위치 |
|---|---|---|---|---|
| 서비스 머리말 | 화면 목적과 현재 연결 상태 표시 | 준비·처리 중·완료·오류 | `ServiceHeader` | 상단 |
| 문의 입력 | 고객 문의 원문 입력 | 빈 값·입력됨·검사 실패 | `InquiryForm` | 왼쪽 본문 |
| 채널 선택 | API의 `channel` 값 선택 | 웹·모바일·전화 | `InquiryForm` | 문의 입력 아래 |
| 문의 전송 | 동기 문의 실행 | 기본·비활성·처리 중 | `InquiryForm` | 입력 영역 하단 |
| 처리 상태 | 요청 처리 진행 상태 안내 | 대기·처리 중·완료·인계 | `ResultPanel` | 오른쪽 본문 상단 |
| 근거 답변 | `answer` 객체 표시 | 빈 상태·답변 있음 | `ResultPanel` | 오른쪽 본문 중앙 |
| 인계 안내 | `handoff_ref` 표시 | 없음·인계됨 | `ResultPanel` | 오른쪽 본문 하단 |
| 오류 안내 | 공개 오류 문구 표시 | 숨김·표시 | `ErrorNotice` | 본문 위 |

## 화면 범위

- `POST /v1/inquiries`의 요청과 응답만 다룸
- 응답의 `result_type`, `answer`, `handoff_ref`, `request_status`만 표시
- 빈 상태·로딩·오류를 최소 형태로 포함
- 관리자·통계·목록·설정 화면 제외
