## 슬라이드 1. 검색 결과 규칙 기반 채점

### breadcrumb

`Ⅲ. 문서 검색 아키텍처 › 6. 규칙 기반 채점`

### 제목

`검색 결과 규칙 기반 채점`

### 리드문

신호 계산 → 판정 규칙 → 행동 3단계로 LLM 없이 채점함. 규칙으로 가르지 못한 「애매」만 재검색 · LLM으로 넘김

### 레이아웃 패턴

**3단 파이프라인 + 하단 콜아웃 1줄** — 헤더 바 3개(① 신호별 기준 · ② 판정 규칙 · ③ 행동)를 좌 → 우 화살표로 연결.  
① 데이터 테이블(가장 넓게), ②③ 판정별 카드 3개를 같은 높이로 맞춰 가로 화살표로 연결.  
하단: 인용 콜아웃 1줄.  
(수정: 「재설계 기준」 4항목 섹션 삭제, 하단 한 줄로 대체)

### 본문 — ① 신호별 기준 (표)

| 신호 | 값의 형태 | 기준 | 판정 역할 |
|---|---|---|---|
| 관련도(Vector) | 연속 점수 | **상한 + 하한** | 3구간 분할 |
| Rerank | 연속 점수(다른 눈금) | **상한 + 하한(별도)** | rerank 모드 3구간 |
| 점수 격차 | 1위 − 2위 | 최소 격차 | 미달 시 애매 강등 |
| 핵심어 일치 | 예 / 아니오 | — | 없으면 부정확 |
| 검색기 합의 | 상위 k 겹침 수 | 최소 겹침 | 미달 시 애매 강등 |
| 하위 질문 충족 | 하위 질문별 판정 | 주 점수 기준 재사용 | 일부 충족 시 애매 |
| 결과 건수 | 개수 | 0건 여부 | 0건이면 부정확 |

- 3구간을 가르는 상한 · 하한은 **주 점수(Vector 또는 Rerank)만** 가짐. 나머지는 판정을 낮추는 조건

### 본문 — ② 판정 규칙 (위에서부터 차례로 검사)

- **부정확 — 하나라도 해당**: 결과 0건 / 주 점수 1위 < 하한 / 핵심어(코드 · 상품명) 불일치
- **정확 — 모두 해당**: 주 점수 1위 ≥ 상한 / 핵심어 포함 / 하위 질문 모두 충족 / 격차 · 합의 기준 충족
- **애매 — 나머지 전부**: 주 점수가 상한과 하한 사이 / 하위 질문 일부만 충족 / 격차 · 합의 미달로 강등
- 카드 아래 캡션: `주 점수 = 모드별 하나(vector · hybrid → Vector, rerank → Rerank) · 위에서부터 차례로 검사`

### 본문 — ③ 행동

- **부정확** → 대체 검색(웹 등)이 있으면 실행 / 없으면 「확인 필요」로 종료
- **정확** → 답변 생성으로 진행 / 판정 근거(신호값)는 로그로 남김
- **애매** → 질문 재작성 후 재검색(상한 있음) / 여전히 애매하면 LLM 평가자(선택)

### 본문 — 하단 콜아웃 1줄

`기준값은 평가셋으로 결정`

### 발표자 노트

- CRAG 원 논문도 채점에 큰 LLM이 아니라 경량 평가자를 쓰고, 신뢰도에 따라 행동을 나눔. 재설계안은 그 평가자를  
  점수 · 문자열 신호와 규칙으로 대신하는 것임.
- 상한 · 하한을 둘 다 갖는 것은 주 점수 하나뿐임. 모드마다 주 점수를 하나만 정하고 두 점수를 섞지 않음.  
  hybrid 융합 점수는 눈금이 또 다르므로 판정에 쓰지 않거나, 쓰려면 기준을 따로 정함.
- 조정할 숫자는 모드당 4개 정도(주 점수 상한 · 하한, 최소 격차, 최소 겹침)로 적게 유지함. 숫자가 늘수록 보정 부담과  
  평가셋 과적합 위험이 커짐.
- 평가셋에서 하한은 "이보다 낮으면 거의 다 오답", 상한은 "이보다 높으면 거의 다 정답"인 지점으로 정함.  
  사이 구간은 일부러 애매로 남겨 재검색 · LLM 평가자에게 넘김.
- 한계: 규칙은 "주제는 맞지만 답이 없는 문서"를 못 거름. 이 빈틈은 답변 후 근거 검증(인용문 원문 대조)과  
  애매 구간의 LLM 평가자가 메움.
