**작성 순서 = 번호임** — `①②③④⑤⑥⑦`.
2026-08-06 사용자 판정으로 기존 `③ 역할`과 `④ 시퀀스`의 **번호와 순서를 맞바꿨음.**
근거는 마이크로서비스 설계 관행임 — `논리 아키텍처 → 시퀀스 → API → 클래스·데이터`.
흐름을 먼저 확정해야 그 단계를 누가 맡고(④) 무슨 지식이 필요한지(⑤) 정해짐.
③의 시퀀스는 **②의 구성요소를 참여 주체로** 그림(④가 아직 없으므로).

## 3. 슬라이드 스크립트 형식 (반드시 이 형식으로 작성)

담당 슬라이드 1장 = 아래 블록 1개. 파일 1개에 담당 슬라이드를 순서대로 이어 씀.

```markdown
## S11. ④ 에이전트 역할 계약서 — 무엇을 정하나

- 패턴: A
- breadcrumb: Ⅱ. 산출물별 작성법 › ④ 에이전트 역할 계약서
- 제목: 혼자 할 일을 여럿에게 나누지 않기
- 리드문: (16pt 한 문장, 45자 이내)

### 좌측 — {헤더바 텍스트}
- (12~16pt 항목. 한 항목 30자 이내. 최대 4개)

### 우측 — {헤더바 텍스트}
- (넘버 배지 항목. 한 항목 35자 이내. 최대 4개)

### 표 (있을 때만)
| 열1 | 열2 | 열3 |
|-----|-----|-----|
| ... | ... | ... |

### 이미지
- 파일명: `s11-single-vs-multi-agent.png`
- 배치: 우측 (또는 하단 전폭 / 좌측)
- 캡션: (12pt, 25자 이내)
- 이미지 프롬프트:
```
(영문 프롬프트 — 5절 규칙 준수)
```

### 강의 노트
(강사가 말할 내용 3~5줄. 슬라이드에는 안 들어감)
```

## 4. 텍스트 분량 상한 (초과 시 클로니가 잘라냄)

| 요소 | 상한 |
|------|------|
| 리드문 | 45자 · 1문장 |
| 좌/우 항목 | 각 4개 이하 · 1개 35자 이하(S13 ⑤ 경로 5가지만 5개 허용 — 판정 J-1) |
| 표 | 슬라이드당 1개 · 5행 이하 · 4열 이하 |
| 슬라이드 총 글자 수 | **250자 이하**(표·캡션 포함, 강의 노트 제외) |
| 최소 폰트 | 12pt (그보다 작아야 할 분량이면 항목을 버림) |

**초급자용 어휘 규칙**
- 가이드의 전문 용어는 **괄호로 쉬운 말을 붙임** — `가드레일(막는 규칙)`, `골든셋(정답지)`
- `HARD`/`SOFT` 같은 부호는 쓰지 않고 `없으면 못 채움` / `나중에 손봐도 됨`으로 씀
- 부호 ID(`G-1`, `F-2`, `T-4`)는 예시 표 안에서만 씀. 본문 문장에 넣지 않음

## 5. 이미지 프롬프트 규칙 (gpt-image-mcp)

**검증됨** — 한글 짧은 라벨은 정상 렌더링됨(테스트 1장 확인). 단 아래를 지킴.

| # | 규칙 |
|---|------|
| 1 | 프롬프트는 **영문**으로 쓰고, 이미지에 넣을 **한글 라벨만 따옴표로 지정**함 |
| 2 | 한글 라벨은 **1개 7자 이하 · 이미지당 8개 이하.** 문장은 절대 넣지 않음.  
`지식/도구`(5자)·`가드레일/관측`(7자)까지 한 줄로 렌더됨을 실측 확인함. 7자를 쓸 때는
프롬프트에 `each node's width adapts to its label so every label sits on ONE line`을 붙임 |
| 3 | 스타일 고정 문구를 반드시 포함: `clean flat vector infographic, corporate consulting style, white background, deep navy #1E2A5C and bright blue #2E74C6 accents, thin gray connectors, generous white space, no gradients on text, no 3D, no photo` |
| 4 | 도식 유형은 5가지 중 1개를 고름 — `흐름도` / `계층 박스` / `판정 트리` / `비교 대조(좌우)` / `경계선 다이어그램` |
| 5 | 크기 `1536x1024`, 품질 `medium`, 형식 `png` |
| 6 | 라벨을 못 넣을 만큼 복잡하면 **번호(1·2·3)만 이미지에 넣고 뜻풀이는 슬라이드 텍스트로** 씀 |
| 7 | **모든 도형에 라벨이나 숫자가 들어가야 함.** 프롬프트 끝에 `EVERY box must contain its Korean label — no empty boxes`를 붙임. 안 붙이면 큰 박스가 텅 빈 채로 나옴(1차 생성 20장 중 6장이 그랬음) |
| 8 | **본문 항목 수와 도식 갈래 수를 같게 함.** 슬라이드가 `5가지`라 쓰고 그림이 4갈래면 초급자가 세다가 걸림 |
| 9 | **숫자를 8개 넘게 요구하지 않음.** 넘으면 모델이 값을 뒤섞음. 대표값 3 ~ 4개만 넣고 나머지는 슬라이드 표로 옮김 |
| 10 | **화살표 방향을 프롬프트에 못 박음** — `the arrow direction must be from A to B, never the reverse`. 안 쓰면 반대로 그려짐 |

**금지** — 아이콘 안에 영어 약어 나열, 손글씨체, 사람 얼굴, 로고, 화면 캡처 흉내.
