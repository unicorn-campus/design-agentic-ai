**갱신 이력**  
- 2026-08-08 `V-02` 케이스 2번 추가로 오버레이 56행과 `V-10` 3건 대응을 더함

**이 문서는 새 단계를 만들지 않음.** ③ 패턴/시퀀스가 확정한 **90단계 위에 태그만 겹쳐 그림**

타임아웃·재시도는 ③이 소유하므로 **인용만** 하고, 값이 어긋나면 12절 `변경요청`으로 되돌림(`G-4`·`G-5`).  
민감 필드 ID(`F-n`)는 ⑤ 지식/도구, 키 이름은 ④ 역할계약서, Mock 구분은 ② 논리아키텍처,
배포 단위·비밀값은 ⑦ 배포가 소유함(`G-11`·`G-12`·`G-10`).

`[확인필요]` **6건** — 말미 미확정 항목 표 6행과 같음. 선행 산출물이 소유한 태그는 따로 셈(16절 규칙).  
**케이스 2 추가로 ⑥이 새로 낸 태그는 0건임** — 새 56행이 요구한 값(승인 세션 만료 · PG SLA ·
배치 실행 창 · 향상률 산출식 · `C-12` 키·배정)은 **전부 ③·④·⑤가 이미 태그로 열어 둔 값**이라
⑥이 같은 태그를 다시 만들지 않고 인용만 함(16절 인용 목록으로 감).

**쉬운 말 옆풀이** — 이 문서에 자주 나오는 낱말임.

| 낱말 | 한 줄 뜻 |
|------|---------|
| 가드레일 | 사고가 나기 전에 막아 두는 장치. 도로 옆 난간과 같은 뜻임 |
| 관측(observability) | 무슨 일이 있었는지 뒤에서 되짚을 수 있게 남기는 기록임 |
| 멱등성 키(`idempotency_key`) | 같은 요청이 두 번 와도 한 번만 처리하게 하는 표식임 |
| 마스킹 | 값을 그대로 남기지 않고 가려서 남기는 것임(뒤 4자리만·전부 별표 등) |
| 스팬(span) | 한 구간이 언제 시작해 언제 끝났는지 재는 기록 한 토막임 |
| 거름망 | 조건 하나라도 걸리면 못 지나가게 하는 방식임. 점수를 더해 넘기는 방식이 아님 |
| 기본 거부 | 허용을 적어 두지 않은 것은 일단 못 하게 막는 원칙임 |

### 7-1. 환산 계산식


**모델을 부르는 단계는 2개임** — `S-R11`(동기 요청) · `S-B5`(스케줄 배치). 몫을 나눠 적음.

```

  S-R11 몫 = 10원/건 × 100%  ·  S-B5 몫 = 예산 밖  →  합이 100%로 닫히지 않음

  실효 단가 = 300만 원 ÷ 60만 콜 = 5원/콜
```

전제 A · B 중 어느 쪽인지는 `[확인필요: 배치 LLM 호출이 월 30만 건 건수 전제에 포함되는지]`

### 7-2. 최악 금액 — 두 항을 따로 세어 곱함

