# ④ 에이전트 역할계약서

> 이 산출물은 키 이름을 정하지 않음. 프로세스별 API 설계·State 필드는 ③,  
> 커넥터 요청·응답 키와 민감 필드는 ⑤ 소유이며 여기서는 논리 이름과 권한 등급만 정함.

## 담당자 명부

| 담당자 ID | 이름 | 종류 | 판정 근거 |
|---|---|---|---|
| `R-L1` | 해석·근거·문서 생성 담당자 | `LLM` | ③의 모델 호출 1회 이상 8개 단계를 배정함. 도구 집합은 다르지만 V-08의 단일 LLM 구성요소와 같은 모델 컨텍스트를 쓰므로 합침 |
