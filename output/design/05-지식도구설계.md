# ⑤ 지식·도구 설계

## 3-1. 정보

### 정형정보

정형 조회 DB와 `S-3` 용어사전, `S-4` LangGraph 체크포인터, `S-5` 이벤트·격리 상태,
`S-6` 지식 개선 대기열, 외부검색 캐시는 PostgreSQL로 확정함.  
접속정보·백업·물리 배치는 구현·운영 단계 범위임.

외부 정형 도구 `상담·거래 분석 뷰`는 ④ 표B에서 `읽기`로 승인된 도구임.  
③의 `S-R3`과 `S-B3`이
각각 SQL을 1회 작성하므로 후속 실행 `S-R4`와 `S-B4`는 제한형 NL2SQL 경로임. `S-B2`는 모델 호출
전의 전일 조건 고정 조회임.  
정형 검색 3단계와 아래 접근 경로 3행이 일치하며 방식 불일치 0건임.
