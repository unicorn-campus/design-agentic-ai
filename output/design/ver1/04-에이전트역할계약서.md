# ④ 역할계약서: 신용카드사 AI Help Desk

> 이 산출물은 키 이름을 정하지 않음. 프로세스별 API와 State는 ③이 소유함.  
> 커넥터 규격과 민감 필드는 ⑤가 소유함.

## 담당자 명부

| 담당자 ID | 이름 | 종류 | 판정 근거 |
|---|---|---|---|
| `R-L1` | 상용 텍스트 생성·판정 담당자 | `LLM` | 모델 호출 단계 5개가 상용 LLM Mock만 사용하므로 도구 집합 기준으로 묶음 |
| `R-D1` | 안전 처리·조회·상태 기록 담당자 | `Deterministic` | 모델 미사용 단계 중 읽기와 되돌릴 수 있는 쓰기 단계 25개를 같은 권한 경계로 묶음 |
| `R-D2` | 설문 발송 담당자 | `Deterministic` | 설문 발송은 되돌릴 수 없는 쓰기이므로 다른 결정론적 담당자와 분리함 |
| `R-H1` | 상담 요약 검토자 | `Human` | `S-E6` 승인과 `S-E7` 재정의가 같은 상담 요약 검토 권한임 |
| `R-H2` | 설문 수신 동의자 | `Human` | `S-E9`와 `S-E10`의 기존 수신 동의가 설문 발송의 사전 승인임 |
| `R-H3` | 설문 발송 감사자 | `Human` | 되돌릴 수 없는 설문 발송을 승인자와 다른 사람이 사후 감사함 |
