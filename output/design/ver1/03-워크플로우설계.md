## 워크플로우별 설계

### `W-1` 고객 문의 처리

**총 시간예산**

- 전체 하드 타임아웃: 15,000ms
- 응답시간 목표: 문의 접수부터 근거 답변 또는 상담사 인계 안내까지 5,000ms 이하(p95)
- 단말 구간을 포함한 End-to-End 예산이며 `S-R1`부터 `S-R11`까지 적용함

**Sequence**

```mermaid
sequenceDiagram
  participant C as 고객
  participant P1 as P-1 고객 웹
  participant P3 as P-3 동기 요청 처리
  participant K as S-2 승인 지식 저장소
  participant T as 조회 API Mock
  participant P2 as P-2 내부 웹
  C->>P1: S-R1 문의 제출과 요청 식별
  P1->>P3: S-R2 요청 접수와 입력 안전 검사
  P3->>P3: S-R3 문의 분류와 경로 선택
  opt 검색·조회 경로
    par 승인 지식 검색
      P3->>K: S-R4 승인 지식 검색
    and 고객·카드·거래 상태 조회
      P3->>T: S-R5 읽기 전용 상태 조회
    end
    P3->>P3: S-R6 근거 답변 초안 생성
    P3->>P3: S-R7 근거·신뢰도·민감정보 검사와 결과 선택
  end
  opt 답변 가능
    P3-->>P1: S-R8 근거 답변 반환
  end
  opt 즉시 인계 또는 검사 결과 인계
    P3->>P3: S-R9 인계 카드 구성
    P3->>P2: S-R10 상담 대기열 생성
    P3-->>P1: S-R11 인계 상태 반환
  end
```

- 최악값 합계: 200(`S-R1`) + 300(`S-R2`) + 500(`S-R3`)
  + max(3,000(`S-R4`), 9,000(`S-R5`)) + 3,000(`S-R6`) + 300(`S-R7`)
  + max(300(`S-R8`), 400+600+300(`S-R9` ~ `S-R11`)) = 14,600ms ≤ 15,000ms임. 통과함

  + max(100, 150+250+100) = 2,800ms ≤ 5,000ms임. 통과함

### `W-2` 상담 지식 개선 배치

**총 시간예산**

- 전체 하드 타임아웃: 14,400,000ms, 02:00 시작 후 06:00 이전 완료
- 배치 완료 목표: 후보 승인 대기 또는 후보 없음 상태까지 14,400,000ms 이하

**Sequence**

```mermaid
sequenceDiagram
```
