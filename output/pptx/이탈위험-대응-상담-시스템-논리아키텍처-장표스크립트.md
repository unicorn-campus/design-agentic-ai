# 이탈위험 대응 상담 시스템 논리 아키텍처

## 장표 목적

한 장에서 시스템 통제 범위와 외부 연계 지점을 확인하고, 각 경계를 통과하는 민감정보를 구분함.

## 제목

이탈위험 대응 상담 시스템 논리 아키텍처

## 핵심 메시지

내부 시스템은 하나의 통제 경계로 유지하고, 사용자·사내 연계 시스템·외부 AI 사업자와의 연결마다
전달 데이터와 민감정보 라벨을 명시함.

## 화면 구성

- 상단: 외부 사용자 경계 `TB-1`
- 중앙: 내부 시스템 경계 `TB-2`와 단일 노드 `이탈위험 대응 상담 시스템`
- 우측 상단: 사내 연계 시스템 경계 `TB-3`
- 우측 하단: 외부 AI 사업자 경계 `TB-4`
- 하단: 민감정보 라벨 `SL-1`부터 `SL-5`까지의 범례와 외부 LLM 미통과 정보

## 관계와 데이터

- 상담사에서 시스템: 회원ID·상담질문·상담사ID
- 시스템에서 상담사: 상담제안ID·제안내용·근거참조·주의사항
- 운영자와 시스템: 색인 시작 요청·원본 문서 경로·색인 완료 시각
- 고객정보계와 시스템: 회원·카드 관계·카드ID·상품ID
- 카드이용계와 시스템: 승인 사용액·연체액·출처·기준 시점
- 외부 예측 AI와 시스템: 회원ID·고객 현황·예측 기간·이탈 확률·위험 등급
- 외부 LLM과 시스템: 비식별 상담질문·선별 근거 문단·질문 해석 결과·상담 제안 초안

## 보안 강조

외부 LLM에는 회원ID·카드ID·상담사ID·상담ID·원문 문서 경로를 전달하지 않음.
