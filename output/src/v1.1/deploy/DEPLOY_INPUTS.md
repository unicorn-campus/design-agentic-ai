# 배포 실행 입력값 목록

실제 값은 이 문서에 기록하지 않음. 필수 값이 없으면 배포 시작 금지.

| 이름 | 어디서 얻나 | 필수 | 보유 주체 |
|------|-------------|:----:|----------|
| 이미지 판 태그 | 커밋 식별자 + UTC 빌드 시각 | 예 | 배포 담당자 |
| 비밀값 K-01 ~ K-15 | 승인된 비밀 저장소 | 실물 판만 | 비밀값 관리자 |
| PostgreSQL 로컬 비밀번호 | 로컬 `.env` | 로컬 Compose | 로컬 실행자 |
| 커넥터 Mock·실물 모드 | ② 논리아키텍처 4절 | 예 | 도구 연동 담당자 |
| OTLP 주소·인증 헤더 | 관측 백엔드 확정 뒤 | 아니오 | 관측 담당자 |
| 직전 정상 이미지 판 | 이미지 저장소 | 예 | 배포 담당자 |
