# 미검증 설계 — 로컬 Docker 되돌리기 절차

실제 운영 배포는 수행하지 않았으며 이미지 판 되돌리기 절차만 정의함.  
이미지 판 표시는 `${커밋 식별자}-${UTC 빌드 시각}` 사용을 권장함.

## 실행 전 확인

1. 현재 `LUNCHPICK_IMAGE_TAG`와 직전 정상 판 태그 기록 확인
2. 데이터 삭제·벡터 커밋·구독 강등 실행 여부 확인
3. 실제 비밀값이 문서·명령 이력·로그에 들어가지 않았는지 확인

## 단위별 되돌리기

| 단위 | 절차 | 데이터 주의점 |
|------|------|--------------|
| 회원 서비스 | 직전 이미지 태그로 Compose 재기동 | 토큰 서명 키 변경 판은 단순 되돌리기 금지 |
| 추천·이력 서비스 | 직전 이미지 태그로 Compose 재기동 | 캐시·이력 삭제 데이터는 코드만으로 복구 불가 |
| 결제 서비스 | 직전 이미지 태그로 Compose 재기동 | 진행 중 결제는 멱등성 키로 대조 후 사람 확인 |
| 프론트엔드 | 직전 정적 이미지 태그로 재기동 | 운영 CDN 사용 시 캐시 무효화 필요 |
| 일일 학습 배치 | 직전 이미지 태그로 교체 | 직전 취향 벡터 1세대 보관 확인 후 실행 |

```powershell
$env:LUNCHPICK_IMAGE_TAG='<직전-정상-판>'
docker compose up -d --no-build
docker compose ps
```

되돌린 뒤 현재 `/health` 응답과 `GA-1` ~ `GA-6` 배포 게이트 확인 필요.  
`/health/live`·`/health/ready` 분리는 API 후속 반영 전까지 확인 필요 상태임.
