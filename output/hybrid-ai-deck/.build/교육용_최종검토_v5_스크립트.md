# 소스 검증 교육용 최종본 v5 제작 스크립트

## 범위와 기준

- v4 55페이지 전체를 소스와 대조하고 3페이지 보충 설명을 추가하여 58페이지 구성
- 원본 4·9페이지 workflow 이미지는 현재 4·24페이지에 원본 그대로 보존
- 상세 페이지 제목에 노드명 유지, 실제 함수·파일 출처를 하단 및 발표자 노트에 표기
- 실행 소스에서 코드를 직접 발췌함. 발췌 시 주석·공백 생략 여부를 구분하고 문법 오류 제거
- 검증된 현재 동작과 개선이 필요한 소스 계약을 구분함. 제품 소스는 수정하지 않음
- 기존 네이비·블루, Pretendard, 16:9 및 편집 가능한 도형·표 형식 유지

## 발표 흐름

먼저 workflow에서 위치를 찾고 입력·출력 필드를 확인함. 이어 실행 함수를 읽으며 상태의 변경을 추적함.
검색 후보, 원 벡터 점수, 융합·RRF·리랭크 점수를 구분하고 최종 결과 절단 시점을 설명함.
자동 검증은 형식·인용의 기계적 검사이며 의미 정확성은 별도 검토 대상임을 강조함.
