# 카드 데이터 ERD 테이블 설명

| 테이블 | 설명 |
|---|---|
| `product(상품)` | 카드 상품과 가족카드 발급 가능 여부·규칙 |
| `product_annual_fee(연회비)` | 상품과 브랜드 조합별 연회비 정보 |
| `member(멤버)` | 회원의 가입일, 고객군, 연령대 등 기본 정보 |
| `card(카드)` | 회원에게 발급된 카드의 상품·브랜드·상태 |
| `delinquency(연체)` | 회원의 월별 연체 일수·횟수·금액 |
| `private_member_id_map(회원번호 대응표)` | 원본 회원번호와 회원 ID의 대응 정보 |
| `merchant(가맹점)` | 거래가 발생하는 가맹점과 업종 정보 |
| `card_txn(거래)` | 카드 결제의 날짜·금액·승인 정보 |
